# Data Science Coursework

Python and Jupyter exercises covering collections, visualization, probability, regression, and correlation.

## Original coursework

- CS 3753-01T — Data Science, Summer 2025

Originally completed at the University of Texas at San Antonio during the terms above and imported to GitHub later. This repository preserves the submitted implementation; repository documentation and import housekeeping were added separately.

**Languages and technologies:** Python, Jupyter, NumPy, Pandas, Matplotlib, SciPy, scikit-learn.

## Implementation

- Python collections and indexing exercises.
- Pandas time-series and Matplotlib visualizations.
- Z-scores, ranks, probability calculations, and matrix/statistical operations.
- Regression and correlation analysis.

## Concepts

- Data transformation, visual presentation, statistical normalization, probability distributions, and interpreting fitted models.

## Repository layout

| Directory | Contents |
|---|---|
| `python-collections` | Python containers |
| `data-visualization` | Plotting and DataFrame exercises |
| `statistics-and-probability` | Statistical exercises |
| `regression-and-correlation` | Regression/correlation exercises |

## Running the source

Create a Python environment with the libraries listed above and open the notebooks in Jupyter. The plotting/statistics exercises reference fdata.csv, Measles.csv, and Mumps.csv; these datasets were absent from the supplied folder and are not fabricated here.
